# 04_reasoning 知识推理 —— 补全图谱缺失的知识

> 现实图谱永远不完整：语料里没写"张勇的老板是马云"，图谱里就没有这条边。
> 推理 = 从已有知识**推断缺失知识**。本目录学最经典的表示学习模型 TransE。

| 文件 | 内容 |
|------|------|
| [01_transe.py](01_transe.py) | TransE 完整小 demo：纯 numpy 实现，训练 + 链接预测 |

## 1. 知识点

### 1.1 推理的两种思路

| 流派 | 方法 | 特点 |
|------|------|------|
| 符号推理（规则） | 逻辑规则：`(a 总部位于 b) ∧ (b 属于 c) ⇒ (a 在 c)` | 可解释，但规则要人写 |
| 表示学习（向量） | 把实体/关系学成向量，向量运算推断缺失 | 自动学，不可解释，本目录主角 |

### 1.2 TransE 核心思想

把每个实体和关系映射到 **d 维向量空间**，学习的目标是让三元组满足：

```
头实体向量 + 关系向量 ≈ 尾实体向量      （h + r ≈ t）
```

- "马云 + 创始人 ≈ 阿里巴巴"、"杭州 + 省会 ≈ 浙江"
- 学完之后，`阿里巴巴 + 总部位于` 向量最接近的实体 = 杭州 → **推理出总部在哪**
- 灵感来源：词向量（word2vec）里 "king - man + woman ≈ queen" 也是向量算术

### 1.3 训练信号：正样本 vs 负样本

- **正样本**：图谱里已有的三元组（希望 h+r 接近 t）
- **负样本**：随机替换头/尾实体的假三元组（如"马云 CEO 阿里巴巴"是假的）
- 模型学的是：让正样本距离小、负样本距离大 → 本质是区分真假的二分类

## 3. 术语速查

| 词汇 | 全称/英文 | 说明 |
|------|------|------|
| TransE | Translating Embedding | 平移嵌入：h + r ≈ t 的向量表示学习模型 |
| 嵌入 | Embedding | 把实体/关系映射成稠密向量的过程 |
| 链接预测 | Link Prediction | 预测缺失三元组的头或尾（图谱补全） |
| 负采样 | Negative Sampling | 造负样本的方法：随机换掉头或尾 |
| Margin Loss | 边际损失 | 让正负样本分数至少差一个 margin 的损失函数 |
